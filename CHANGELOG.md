# Изменения

## 0.2.0 — 2026-11-04

Большое обновление: команда агентов, ассистент, доступ из интернета, мультиаккаунты и единый менеджер обновлений CLI.

### Агенты и работа
- **Команда агентов** (`lib/team.mjs`): ведущий составляет план, владелец утверждает, шаги выполняют агенты по ролям (Claude Code, Codex, Kimi, Gemini) в одной папке. Если упали тесты, шаг возвращается на доработку, в конце ведущий делает ревью.
- **Ассистент** (`lib/assistant.mjs`): кнопка-«волна» и живой голосовой разговор о проектах. Факты берутся из Depo, поиск по коду — у агента, который только читает.
- **Очередь уточнений** (`lib/queue.mjs`): сообщения во время хода доходят до агента. Claude получает их «на ходу» (подтверждение по эху), Codex и Kimi — следующим сообщением. Защита от двух пишущих агентов в одной папке.
- **Передача между агентами** (`lib/handoff.mjs`): сводка задачи, фактический `git status` и коммиты. Свежие реплики не теряются.
- **Общая память проекта** (`lib/memory.mjs`): `.depo/memory`, уроки прошлых задач (`LESSONS.md`), автосводка хода.
- **Собеседник**: режимы «Объяснить» и «Подготовить уточнение», источники, вырезание секретов.
- Проверки и безопасная публикация (`lib/safety.mjs`, `.depo/checks.json`): тесты, проверка после выкладки, откат. Таймер хода, квоты, компактная панель выполнения, итоги и умные уведомления.

### Аккаунты и обновления
- **Несколько аккаунтов** у Claude, Codex, Gemini и Kimi: почта, тариф и лимиты у каждого, переключение в один клик. Живые лимиты Codex через `codex app-server`.
- **Единый менеджер обновлений CLI** (`lib/cli-update.mjs`) для Claude Code, Codex, Kimi Code и Gemini CLI: ставит только проверенные версии (выдержка npm 48 ч, канал stable у Claude), сторож с автооткатом, понимает обёртки с прокси.

### Доступ и безопасность
- **Удалённый доступ через проводник** (`lib/remote.mjs`, `deploy/relay/`): VPS с NetBird и socat, Nginx Proxy Manager и Let's Encrypt на своём домене. Готовый `docker-compose.yml` и скрипт `npm-add-host.mjs`.
- **Скрытый сайт-маскировка** (`public/site/`): снаружи на главной обычный сайт, вход только по секретному адресу (по умолчанию `/enter`, меняется в настройках). Остальное отдаёт пустые 404, после N неверных паролей доступ выключается сам. Тумблер в настройках и в Telegram-боте.
- **Код из Telegram на новом устройстве** (`lib/twofa.mjs`). Сессия: выход после 14 дней без заходов, максимум 90 дней.
- **Свой TLS** (`lib/tlscert.mjs`): Depo сам дописывает в сертификат новые адреса (IP проводника, имя в NetBird).
- Пин-код и отпечаток на телефоне. Симлинки не выпускают файлы за пределы проекта.

### Интерфейс
- **Главная-дашборд**: активные задачи, лимиты, проекты, статистика, службы, карточка «Сервер» (CPU, RAM, диск, температура, аптайм; `lib/sysinfo.mjs`).
- **Premium Dark**: глубже фон, золотые акценты, свечение индикаторов, единая сетка 4→2→1.
- **Телефон**: экраны «Проекты» и «Чаты» вместо выезжающей панели, жест «назад», нижняя навигация, заставка PWA, поиск по чатам всех проектов.
- **PWA и web push** (`lib/push.mjs`): установка на экран, уведомления через VAPID и aes128gcm на `node:crypto`, без внешних библиотек.
- Кликабельные пути к файлам в ответах агентов (`public/file-links.js`), черновики, кнопка «вниз», окно ленты на 200 сообщений.

### Голос
- Три движка диктовки на выбор для каждого устройства: на сервере (Vosk + Whisper), в браузере (Web Speech API), «ChatGPT через Codex» (`lib/chatgpt-voice.mjs`, экспериментально).

### Обслуживание
- **Уборка** (`lib/housekeeping.mjs`): журнал и старые данные чистятся сами.
- Telegram `/pi`: список служб и дисков задаётся через `DEPO_TG_SERVICES` и `DEPO_TG_DISKS`.
- Новые переменные окружения описаны в `.env.example`.
- `npm run check:ui`: прокликивает интерфейс в Chromium и ловит ошибки консоли.
